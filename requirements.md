# Software Requirements

## Project Name
Classroom Attendance System

## 1. Functional Requirements

**FR-01: Display Attendance Records**  
The system shall display each student's name and attendance status.

**FR-02: Count Present Students**  
The system shall count the number of students marked as Present.

**FR-03: Count Absent Students**  
The system shall count the number of students marked as Absent.

## 2. Non-Functional Requirements

**NFR-01: Usability**  
The program shall display attendance records and summaries in a clear, readable format.

**NFR-02: Performance**  
The program shall process the sample attendance records and display the summary without unnecessary delay.

## 3. Sample Program Requirements

- The program shall use Python.
- The program shall use fictional student records for demonstration.
- The program shall display the number of present students, absent students, and total students.

## 4. Scope and Limitations

This is a basic demonstration program. It uses predefined attendance records and does not include a database, graphical user interface, student login, or attendance editing.

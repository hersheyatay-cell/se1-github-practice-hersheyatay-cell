\# Classroom Attendance System



\## Project Description

A simple Python program that displays student attendance records and summarizes the number of students present and absent.



\## Problem Statement

Recording and counting student attendance manually can take time. This project demonstrates a simple way to display attendance records and calculate attendance totals.



\## Intended Users

\- Teachers

\- Classroom advisers

\- Students learning Python



\## Features

1\. Displays student names and attendance status.

2\. Counts students who are present and absent.

3\. Displays the total number of students.



\## Sample Program

The `sample\_program.py` file contains fictional student attendance records for demonstration.



\## How to Run

1\. Install Python.

2\. Open Command Prompt in the project folder.

3\. Run:



&#x20;  `python sample\_program.py`
